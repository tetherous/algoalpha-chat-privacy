# AlgoAlpha Chat for TradingView

An AI Pine Script assistant inside TradingView. Describe an indicator in plain words and it writes the Pine Script, checks that it compiles, and adds it to your chart. You can also edit scripts, add TradingView's built-in indicators, and ask about your chart's data, all by chatting.

This repository only holds the extension's public pages. It has no source code.

- [Privacy policy](PRIVACY.md)
- [Support: report a problem or ask a question](https://github.com/tetherous/algoalpha-chat-privacy/issues)

## What you need

- A TradingView account (free plans work).
- Your own API key from Anthropic (Claude) or OpenAI. Usage is billed by that provider to your account.

## Privacy in short

Your API key stays in your browser. Your messages, plus the script and chart details needed to answer them, go only to the AI provider you choose. There are no accounts, analytics or tracking. See the [privacy policy](PRIVACY.md) for details.
